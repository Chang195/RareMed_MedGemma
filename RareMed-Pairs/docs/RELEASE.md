# 本地工作区与 GitHub 代码包

本项目公共发布范围是脚本、配置、来源版本锁、方法说明和汇总统计，不是原始医学图像数据集的重新分发。

`python tools/release_project.py --build` 按明确允许清单生成代码 ZIP，而不是压缩整个工作目录。它检查保留脚本哈希、模块依赖、异常大文件、常见私钥/API token 形态和个人绝对路径。扫描不是完整安全审计。

以下内容保留在本地并由 `.gitignore` 排除：

- `data/`：检索缓存、文章、图片、模型请求与响应、病例文本及训练划分。
- `models/`、`.venv*/`、`.cache/`：模型和环境。
- `reports/`、`output/`：含原文、图片或个人文件路径的本地报告和演示稿。
- SFT 混合实验目录中的 inputs、images、dataset 和 manifests；公共包仅带构建与检查代码。

先前的旧脚本、旧说明、旧候选版本、临时构图文件和已取消的新数据采集已移动到项目同级的 `RareMed-Pairs_local_archive_20261028/`。`archive_receipt.json` 保留原路径和逐文件 SHA-256。恢复时按原路径取回需要的文件；不要把整个归档重新覆盖到主项目。

本地 `metadata/cleanup_summary.json` 记录清理结果；它包含个人路径，不进入公共包。

## 结果可复现的边界

1. **公开离线复算**：`results/cluster_confusions.json` 只含混淆计数向量及重复次数，无文章 ID、病例 ID、病例原文或图片。可以精确重算最终按病种分组的 Precision、Recall、F1 和来源分组 bootstrap 置信区间。不是重新运行信息抽取模型。
2. **从来源重跑流程**：按 `metadata/source_lock.json` 下载固定版本 MedPix/MultiCaRe 来源文件，按 README 执行采集和评测。检索库更新、可用全文变化和在线 LLM 版本变化可能造成不同输出；不要声称新 API 调用能逐字节复现旧结果。
3. **本地历史回放**：保留的原始检索快照、API 缓存、权重版本和各阶段哈希用于验证原实验。完整逐条核验需要这些未随公共代码包分发的本地文件。
