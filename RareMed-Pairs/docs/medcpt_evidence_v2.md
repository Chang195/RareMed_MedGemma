# MedCPT 证据检索改进版

从 RareMed-Pairs 的 VS Code 终端运行：

```powershell
.\.venv-medcpt\Scripts\python.exe scripts/medcpt_batch_v2.py --limit 10
```

旧版 `medcpt_pilot10` 保留。新版默认输出 `data/processed/medcpt_pilot10_v2_1/`。
首轮改进试验 `medcpt_pilot10_v2` 也保留；v2.1进一步拒绝遗传风险说明充当检测结果、临床诊断句充当影像观察。
不调用 API；仅使用已下载权重进行本地推理。每篇结果完成后写入检查点，
相同计划重复运行会复用已完成的文章。代码、输入或模型清单改变时，须指定新输出目录。

## 改动

1. 临床查询拆为主诉/症状、既往史、家族史、年龄四类，另有影像、检查结果和基因/病理结果查询。
2. 在原文段落块中切句，保留字符起止位置；先做保守的字段线索筛选，再进行MedCPT召回和重排序。
3. 临床输入候选拒绝明显的诊断/基因泄漏、群体描述、治疗内容。可能误拒混合句，拒绝不代表事实不存在。
4. MRI候选拒绝纯CT句、混合CT/MRI句和仅描述安排/讨论检查的句子。否定原句完整保留。
5. 诊断结果检索排除治疗句；已有作者诊断和依据的原文引用直接复用并逐字核对，不重新生成。
6. 保留原图注。图号引用处理支持数字范围（Figures 2–3），拒绝将Figure 20误匹配成Figure 2。
   同一句涉及多幅图时保留为歧义，不自动分配其全部表现给每幅图。不会把eFigure误匹配为主文Figure。
7. 字段可返回空列表；不通过任意logit阈值宣称可靠性。返回的是规则合格候选，仍不是经核验的证据。

## 输出

- 每篇 `PMC编号.json`：7类候选池、规则筛选计数和原文位置。
- `evidence_records.jsonl`：图片、图注、既有诊断/依据引用、图号引用句段和候选池路径。
- `comparison.csv`：同一文章的旧版首位段落与新版各字段首位句子，供人工比较。
- `summary.json`：数量及覆盖情况；不等于准确率。

所有检索结果均不声明患者归属已验证。CASE仅是章节约束；没有CASE章节则回退正文。
没有病例范围核验、像素审核、跨文章患者去重或独立语义审核，不直接生成SFT样本。
临床过滤只是显式词语启发式，不是完整脱敏或答案泄漏检测。
原文分句也有局限：长段落切块可能截断句子，缩写及隐式图号指代可能漏掉。
图注可以包含统计图或多患者面板，来源是图注不等于训练内容已经合格。

扩大到全部时指定新的输出目录，保持前10篇对比结果：

```powershell
.\.venv-medcpt\Scripts\python.exe scripts/medcpt_batch_v2.py --limit 370 --output data/processed/medcpt_all_v2
```

建议先检查试运行结果。该候选源有317篇具备已有模型关联；`--limit 370`只会选择实际存在的文章。
